# Граф зависимостей расширения 1С

Строит граф зависимостей объектов из XML-выгрузки конфигурации 1С
(Конфигуратор → Выгрузить конфигурацию в файлы).

## Когда использовать

Когда пользователь просит:
- «покажи архитектуру», «как связаны объекты»;
- «какие регистры пишет документ X»;
- «на какие справочники ссылается объект Y»;
- «нарисуй граф зависимостей».

## Как выполнять

Запусти скрипт (самодостаточный, без зависимостей, Node):

```bash
node .opencode/skills/1c-architecture-graph/graph.mjs <путь_к_выгрузке>
```

Путь по умолчанию — `20260824/20260824` (корень проекта). Если выгрузка в другом
месте, передай путь первым аргументом.

Скрипт выводит:
1. Сводку по типам объектов.
2. Текстовый граф: документы → регистры (движения), регистры → справочники,
   документы → справочники, справочники → справочники.
3. Тот же граф в формате Mermaid (`flowchart`).

## Как интерпретировать

- **Документ → РегистрНакопления/РегистрСведений** — из элемента `<RegisterRecords>`
  документа (это движения, которые документ формирует). В расширении это только
  добавленные регистры (типовые регистры ERP не выгружаются).
- **Любой объект → Справочник/Документ/Перечисление** — из типов реквизитов,
  табличных частей, измерений/ресурсов (`cfg:CatalogRef.*`, `cfg:DocumentRef.*`,
  `cfg:EnumRef.*`).
- Ребро «пишет в» важнее ребра «ссылается на» — помечай это в ответе.

## Ограничения

- Выгрузка расширения содержит только заимствованные/собственные объекты; типовые
  регистры ERP (куда документы пишут штатно) в граф не попадают.
- Связи из текста запросов (отчёты/СКД) не парсятся — только метаданные.
