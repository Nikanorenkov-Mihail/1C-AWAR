# Векторный поиск по проекту 1C-AWAR

Локальный семантический поиск по коду (`.bsl`) и метаданным (`.xml`) расширения 1С.
Без внешних API: модель эмбеддингов скачивается один раз и работает офлайн.

## Установка

```powershell
cd vector-search
npm install
```

При первом запуске Transformers.js скачает модель `Xenova/paraphrase-multilingual-MiniLM-L12-v2`
(~120 МБ, нужен интернет один раз).

## Индексация

```powershell
npm run index
```

Создаёт `index.json` (чанки + векторы) по выгрузке `20260824/20260824/`.

## Поиск

```powershell
npm run query "как рассчитывается чистый вес"
npm run query "проведение движений драгоценных металлов"
npm run query "виртуальные узлы спецификаций"
```

## Что индексируется

- **BSL** — каждый модуль разбивается на процедуры/функции + шапка модуля (комментарии).
- **XML** — `Configuration.xml` и метаданные объектов (имя, синоним, комментарий, состав).

## Настройка

- Модель: константа `DEFAULT_MODEL` в `src/embed.ts`.
- Путь к выгрузке: `DUMP` в `src/index.ts`.
- Топ-N результатов: `slice(0, 8)` в `src/query.ts`.
